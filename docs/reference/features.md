# Features

Every user-visible capability of `github.com/ubgo/appdir`, read from the code, with the guide section that explains it and the example that runs it. An example is linked only when its code calls the feature's API (checked by searching the example's Go files for the identifier, variable or file the feature is about). A dash with a reason means the feature cannot run here (Windows only, root only, two disks, a property); a plain dash means no example calls it yet. For the order to read the guides in, see the [learning path](../README.md).
